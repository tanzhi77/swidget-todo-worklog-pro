# 待办与工作记录 Pro

当前版本：1.0.2

工作月历离线标注中国大陆 2025、2026 年节假日放假及调休上班安排：红色“休”为官方放假区间（含连休、调休日），蓝色“班”为调休上班日，普通周末不标“休”。点击日期可查看完整名称。其他年份提示数据未收录，不自动推算。该标注不改变待办的重复规则。

数据来源：[2025 年国务院办公厅通知](https://www.gov.cn/zhengce/content/202411/content_6986382.htm)、[2026 年国务院办公厅通知](https://www.gov.cn/zhengce/content/202511/content_7047090.htm)。新年份需更新内置 china-holidays.js 数据。

主操作按钮采用灰调蓝 #526FA3，禁用时显示灰色。双周报弹窗的“复制”按钮可直接复制当前预览的编号内容，不包含文件编码标记。

双周报快捷选择支持“本周为第一周”（本周一至下周日）和“本周为第二周”（上周一至本周日）。仍可直接修改起止日期；月历工具栏顺序为换行、导出双周报、导出 CSV。

工作月历右上角“导出双周报”支持选择起止日期、预览并另存为 TXT。“当前双周”定义为本周一至下周日，包含起止当天；也可自选跨月、跨年的范围。按工作日期排序，每项一行，格式为“1、标题”。包含独立工作项及关联待办工作项（含未完成），不含未标记工作项的普通已办；不受月历当前搜索和筛选影响。不同日期同名工作项仍分别保留。

已办显示设备本地实际完成时间；完成图标居中。月历右上角换行按钮可切换事项标题换行，并保存该设置。

修复保存窗口尚未关闭时下载被取消的问题：先确认导出位置，再创建并立即接受下载请求。JSON 与 CSV 均使用此流程。

月历默认占屏幕宽度约 74%、高度约 78%，打开时居中。滚动条采用细圆角样式。

导入时选择本地 JSON 文件；导出 JSON 或 CSV 时弹出另存为窗口，可选择目录并修改文件名。保存完成后提示完整路径，取消导出不会提示成功。

本版修复 Sapphire 直接赋值持久化属性时的状态恢复，日期和时间使用页面内选择器。日期也可输入 YYYY-MM-DD，时间可输入 HH:mm。

勾选“计入工作项”后，未完成事项按截止日期（无截止日期则按创建日期）出现在工作记录和月历，标注“未完成”；完成后按实际完成日期显示，月历全部视图去重。

月历默认 1440×990，最小 1080×780，页面缩放 150%。编辑面板加宽，底部保留保存和取消操作。

桌面主页面采用 150% 缩放，辅助文字最小 13px，并提高浅色和深色文字对比度。建议组件至少使用 420×420 的显示区域。

## 主要功能

- 记录待办、截止日期与时间、优先级、标签、子任务和重复周期。
- 独立记录当天或历史日期的工作项。
- 为待办启用“计入工作项”，完成后自动写入实际完成日期。
- 使用独立月历窗口按月查看工作项和已完成待办。
- 支持搜索、筛选、排序、归档、撤销、JSON 备份导入和月份 CSV 导出。
- 所有下拉菜单均在组件页面内绘制，兼容 Sapphire 桌面嵌入模式，不调用可能导致 Qt 崩溃的原生下拉弹层。

## 基本操作

待办列表每项右侧的“复制标题”按钮可直接复制完整标题，进行中、已完成及归档列表均可使用。

右侧保留复制、编辑和更多操作三个按钮。删除以及归档／恢复位于“更多操作”菜单；手动排序时左侧显示拖动手柄。

1. 在“待办”或“工作记录”页顶部输入标题并确认，即可快速新增；“工作记录”可同时选择记录日期。
2. 点击列表内容打开编辑面板。待办可设置日期时间、优先级、普通标签、子任务和每天、工作日、每周或每月重复。
3. 待办编辑面板中的“计入工作项”对应保留标签“工作项”。待办完成后自动生成关联工作记录；重新打开、移除该标签或删除待办后，关联记录同步移除。
4. “今天、近期、全部”待办在手动排序模式下可拖动六点手柄排序，也支持聚焦手柄后使用上下方向键。删除、完成、归档及排序可在底部提示中撤销。
5. 点击右上角月历按钮打开独立工作月历窗口；重复点击会聚焦已有窗口。
6. 月历支持上月、下月、回到本月、关键词和标签筛选。点击日期可查看详情，并通过右上角加号补录工作项。

## 月历口径

- “工作项”包括独立工作记录和由待办自动生成的关联记录。
- “已办”按待办的实际完成日期统计，不使用截止日期。
- 带“工作项”标签的已完成待办在“全部”视图中只显示一次，并同时标记“工作项”和“已办”。
- 每个日期格利用剩余高度展示事项，超过格子容量后可在格内滚动，完整内容也可在右侧日期详情查看。无固定三条限制。

## 数据说明

- 数据按小组件实例独立保存，不同实例可分别用于工作、生活等场景。
- 自动关联的工作记录跟随源待办，不能作为独立工作项单独修改。
- JSON“合并导入”按记录 ID 和更新时间保留较新内容；“覆盖导入”使用备份内容替换当前数据。
- 旧版 `localStorage.todos` 数据只在用户主动选择后导入，原数据不会被删除。
- 月历的“导出 CSV”始终导出当前月份完整的工作项与已办清单。

## 使用边界

- 组件完全离线运行，不使用网络权限。
- 不包含云同步、Windows 系统通知、附件、工时统计或项目管理功能。
- 在普通浏览器预览中，月历优先使用弹出窗口；被浏览器拦截时会在当前页面打开。Sapphire 中由 QML 创建独立窗口。
